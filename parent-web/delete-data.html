Delete SafeSteps Data

Parents can delete their SafeSteps account and linked child location data from the parent dashboard.

In-App Deletion

Log in to the parent dashboard, then choose Delete account. This removes child profiles, pairing sessions, location history, and active parent sessions.

Support Request

If you cannot access your account, contact support from the email address used for SafeSteps and request account deletion.

Retention

Location history is automatically retained for the configured route-history period, currently 30 days by default, unless the account is deleted sooner.
