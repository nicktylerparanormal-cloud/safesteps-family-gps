SafeSteps Privacy Policy

SafeSteps Family GPS uses child device location only to provide family safety features requested by the parent or guardian.

Data We Collect

We collect parent account details, child profile names, pairing records, device tokens, and location points while sharing is active.

How Data Is Used

Location data is shown to the linked parent account for live location, route history, and safety alerts. We do not sell child location data.

Retention

Location history is retained for a limited period configured by the service, currently 30 days by default, then deleted.

Control

Sharing can be stopped from the child phone. Parents can request account deletion from the dashboard or support channel.
