## Full Description

SafeSteps Family GPS by Tylabs Media helps parents stay connected with their children through simple, transparent family location sharing.

Parents can add children, pair each child's Android phone, start or stop tracking, enable auto tracking for selected children, and view live location on a family map. SafeSteps also supports journey history so parents can review where a child has been during a chosen time period.

Key features:

- Live child location map
- Child phone pairing code
- Start, stop, and auto tracking modes
- Route history and journey replay
- Multiple children on one parent account
- Battery and last-seen status
- Safe-zone ready architecture
- Visible tracking notification on the child's phone
- Built for family safety, consent, and transparency

SafeSteps is not a hidden tracking app. The child phone app shows when location sharing is active and provides clear permission prompts.

## Privacy Positioning

SafeSteps uses location data only to provide family safety features such as live map location, route history, safe-zone alerts, and child phone status. Location sharing must be set up by a parent or guardian and requires permissions on the child device.
